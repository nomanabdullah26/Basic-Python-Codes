## Getting Started

### Requirements

-   Python 3
-   Jupyter Notebook or JupyterLab

You can also open `.ipynb` notebooks using environments such as Google
Colab or Visual Studio Code with the appropriate Python and Jupyter
extensions.

### Run the notebooks

1.  Clone or download this repository.

2.  Open a terminal in the repository folder.

3.  Install Jupyter if it is not already installed:

    ``` bash
    pip install notebook
    ```

4.  Start Jupyter Notebook:

    ``` bash
    jupyter notebook
    ```

5.  Open a notebook and run its cells in order.
